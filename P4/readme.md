# 4. Prototipo Funcional 

En esta fase final, hemos transformado nuestro diseño en un producto interactivo real. Para ello, hemos ido más allá del prototipado convencional, utilizando Figma Make (GenUI) para generar una aplicación funcional mediante instrucciones de lenguaje natural.

### Enlace al Proyecto

Podéis acceder a la versión desplegada y operativa de la aplicación de Sushi Maki a través del siguiente enlace:

https://carrot-nova-33804017.figma.site

Para el desarrollo de este entregable, hemos aplicado el concepto de Vibe Coding, interactuando con agentes de IA para refinar la interfaz y la lógica de navegación:

* Generación de Contexto: Se han integrado todas las pantallas del diseño (Landing, Catálogo, Detalle, Carrito) en el entorno de Figma Make para que la IA comprendiera el flujo completo del usuario.

* Iteración por Lenguaje Natural: En lugar de codificar manualmente, realizamos ajustes de diseño y funcionalidad mediante "prompts". Por ejemplo, solicitamos a la IA: "Añade un mapa de ubicación dinámico en la sección de contactos y ajusta los botones de reserva para que resalten sobre el fondo salmón".
